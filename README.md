# Ningoshi Fisher YT Downloader

A Python-based YouTube video downloader that uses yt-dlp to download videos from supported platforms.

## Features

- Download videos using a simple Python script
- Uses yt-dlp for reliable downloading
- Automatically updates yt-dlp to the latest version
- Easy to set up and use
- Lightweight and beginner-friendly

## Requirements

- Python 3.10+
- Internet connection

## Installation

1. Clone this repository:

```bash
git clone https://github.com/YOUR_USERNAME/ningoshi_fisher.git

pip install -r requirements.txt
python main.py
